## III. QUY CHUẨN XUẤT BẢN HÌNH ẢNH SAU KHI CHỤP / TẠO MỚI

Khi doanh nghiệp chụp ảnh thật hoặc tạo ảnh bằng AI:
1. **Lưu file gốc:** Đặt vào thư mục `assets/images/` với tên theo đúng định dạng `[Số]_[Mo_Ta_Khong_Dau].png`.
2. **Chuyển đổi WebP:** Sử dụng script `scripts/convert_images.py` để nén sang định dạng `.webp` với chất lượng 82%, giữ nguyên metadata và kích thước chuẩn.
3. **Cập nhật Manifest:** Thêm entry vào `research/image-manifest.json` gồm các trường:
   - `filename`, `webp_filename`
   - `alt`, `title`, `caption`
   - `context`, `district_or_route`
   - `aspect_ratio`, `width`, `height`
4. **Cập nhật code HTML:** Thay thế thẻ `picture_tag(...)` tại script sinh trang tương ứng (`scripts/generate_locations.py` hoặc `scripts/generate_services.py`) và chạy lại lệnh build.
